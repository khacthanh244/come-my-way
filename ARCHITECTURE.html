B Pipeline nạp dữ liệu (Ingestion) — offline

File: backend/scripts/ingest.py · embeddings: paraphrase-multilingual-MiniLM-L12-v2 (đa ngôn ngữ, hỗ trợ tiếng Việt)

Quét thư mục tài liệu

data/pdfs/*.md và *.pdf → PyPDFLoader (PDF) / TextLoader (Markdown). Gắn metadata["source"] = tên file để sau này trích dẫn nguồn.

Chia nhỏ (chunking)

RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=200) — mỗi chunk ~1000 ký tự, gối đầu 200 ký tự để không mất ngữ cảnh ở ranh giới.

Embedding (vector hoá)

HuggingFaceEmbeddings biến mỗi chunk thành vector số. Model đa ngôn ngữ chạy CPU, không cần API key.

Lưu vào ChromaDB

Chroma.from_documents(...) → persist vào backend/chroma_db/, collection merchant_docs. Đây là "bộ nhớ" tri thức của agent.

D Backend RAG — luồng xử lý 1 câu hỏi

Request đi vào routes/chat.py → logic ở services/rag.py. Backend KHÔNG lưu trạng thái (history client gửi lên).

Nhận request — POST /api/chat

Body: { message, history[], stream:bool, persona }. Nếu stream=true → StreamingResponse (SSE); ngược lại trả JSON. Lỗi → HTTP 500.

Dựng query truy hồi — _build_retrieval_query()

Ghép 2 lượt hỏi gần nhất của user + câu hỏi mới. Lý do: câu follow-up ngắn ("như sao?") embed kém nếu đứng một mình → cần neo ngữ cảnh.

Truy hồi vector — _retrieve()

get_vectorstore() (singleton @lru_cache) → as_retriever(k=5) → lấy 5 chunk liên quan nhất từ ChromaDB. Kèm tên file nguồn.

Ghép prompt — _build_agent_message()

Nối thành 1 chuỗi: SYSTEM_PROMPT (persona "Sky Agent" + luật Path A/B) + PATH_CONTEXT[persona] + tài liệu + lịch sử (tối đa 10 lượt) + câu hỏi mới.

Gọi LLM — _call_agent()

httpx.AsyncClient.post(agent_endpoint_url, {message: prompt}) tới AgentBase Runtime (timeout 120s). Kiểm tra status == "success" → lấy data["response"].

Stream trả về — rag_stream()

① Gửi dòng nguồn [SOURCES]a.md,b.md[/SOURCES] trước. ② Agent trả full text 1 lần → backend "phát lại" từng từ qua SSE (delay 0.02s) tạo hiệu ứng gõ chữ. ③ Kết thúc [DONE].

Định dạng SSE: data: [SOURCES]...[/SOURCES] data: "từ " data: "tiếp " data: [DONE]

G Đóng gói & triển khai (Deployment)

Multi-stage Docker → 1 container duy nhất serve cả frontend + backend → VNG AgentBase Runtime, port 8080.

Stage 1 — Build frontend

node:20-slim → npm ci → npm run build (tsc + vite) → ra thư mục dist/.

Stage 2 — Backend runtime

python:3.12-slim → cài requirements + torch CPU + sentence-transformers. Pre-download embedding model vào image (tránh cold-start). Copy app/, chroma_db/, data/ và dist/ → /static.

Entrypoint — app/serve.py

Bọc app.main:app, thêm GET /health (runtime yêu cầu) và mount _SPAStaticFiles phục vụ SPA — route /mc, /dev fallback về index.html thay vì 404.

Chạy

uvicorn app.serve:app --host 0.0.0.0 --port 8080 trên AgentBase Runtime (VNG Cloud). Cấu hình theo .agentbase-state.json.
